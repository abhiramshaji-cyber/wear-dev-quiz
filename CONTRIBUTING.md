# Contributing

Issues and pull requests are welcome. This is a small project, so the bar is
simple: keep each change focused on one thing, and say why in the description.

## Getting set up

```sh
./gradlew assembleDebug
```

Then install the APK on a round Wear OS watch or the Wear OS emulator.

## Before opening a pull request

- Test on a round display. A layout that only looks right on a square emulator is
  not finished.
- Say which watch and which Wear OS version you tested on.

## Adding questions

Questions are the most welcome contribution. Both lanes have a bar:

- **TypeScript and JavaScript.** A snippet and two possible results, testing
  language behaviour rather than trivia. Aim for things a working developer uses
  daily and still cannot answer cold. Every question needs the one line reason
  shown on a wrong answer.
- **Québec French.** Connected chunks you can actually build a sentence from, not
  isolated vocabulary. Keep the register Québécois rather than metropolitan.

Two answers only, and the correct one must be genuinely defensible. A question
where both answers are arguable is worse than no question.

Issues labelled `good first issue` are self contained and a good place to start.
